# ConvenientNote

一款原生 WPF 便签与笔记应用。

## 笔记功能

- “笔记”页面默认使用可拖动的便签墙，双击便签进入大编辑器。
- 编辑器支持标题、字号、粗体、斜体、下划线、删除线、列表、对齐、文字颜色、撤销和重做。
- 支持从文件插入图片、拖放图片和直接粘贴剪贴板图片。
- 支持搜索、标签、工作/学习/生活笔记本、置顶、收藏和自动保存。
- 删除的笔记进入回收站，可以恢复或彻底删除。
- 长笔记支持三级章节标题、正文折叠和右侧目录。标题左侧箭头可折叠到下一个同级或更高级标题之前，目录可直接跳转，并支持全部折叠或展开。
- 目录仅显示章节，旧版独立段落的导航标记会在打开时转换为一级章节，保留原格式。右侧“按编号生成章节…”会列出候选段落，勾选确认后生成一级章节，保留原有文字格式。
- 正文搜索包含折叠内容，命中时展开对应章节。章节和折叠状态随笔记保存，重新打开后恢复；标题末尾按回车继续写普通正文。

数据保存在 `%LocalAppData%\ConvenientNote`：SQLite 数据库为 `ConvenientNote.db`，图片位于 `Media` 目录。旧“待测试”页面的数据继续作为笔记显示，不会被复制或清除。

快捷键：`Ctrl+S` 保存，`Esc` 返回笔记墙；编辑器中可以使用 WPF 标准的 `Ctrl+B`、`Ctrl+I`、`Ctrl+U`、`Ctrl+Z` 和 `Ctrl+Y`。

长笔记快捷键：`Ctrl+Alt+1/2/3` 设置当前段落为对应级别章节，`Ctrl+Alt+0` 恢复正文，`Ctrl+Alt+←/→` 折叠或展开当前章节，`Ctrl+F` 搜索正文，`Enter`（搜索框内）或 `F3` 查找下一处。章节标题需独立成段；自动换行不拆分章节，列表项需先取消列表格式再设为章节。
