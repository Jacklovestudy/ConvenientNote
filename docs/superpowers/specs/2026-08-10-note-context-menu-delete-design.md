# 便签右键删除设计

## 目标

在便签的右键菜单中增加“删除便签”，点击后立即永久删除当前便签，不显示确认框。

## 交互

- 在便签空白区域右键时，显示包含“删除便签”的菜单。
- 在标题或正文输入框内右键时，保留剪切、复制、粘贴和全选，并在分隔线后追加“删除便签”。
- 点击“删除便签”后关闭菜单，调用当前工作区的删除能力；成功后便签立即从当前视图消失，并重新计算画布尺寸、空状态、摘要和“整理便签”按钮状态。
- 删除为现有的硬删除语义，不进入回收站，也不提供撤销。

## 实现边界

- 复用 `WorkspaceApplicationService.DeleteNoteAsync`，不新增领域或数据库删除逻辑。
- 在 `TodoBoardViewModel` 增加面向单个便签的异步删除入口，成功后刷新工作区数据。
- 右键菜单沿用当前 `TodoBoardControl` 的事件转发模式，将菜单对应的 `CanvasTodoViewModel` 交给页面 ViewModel。
- 不改变便签的拖动、编辑、优先级或完成状态行为。

## 错误处理

- 数据层删除异常时保留便签，避免界面显示已删除但数据库仍存在。
- 异常沿用当前页面的调试日志方式记录，不弹出额外确认或错误对话框。

## 测试

- ViewModel 测试验证：删除现有便签会调用真实应用服务并从重新加载的工作区中消失。
- 验证删除后视图状态刷新，包括便签集合、空状态和画布尺寸。
- 构建 WPF 项目，检查 XAML 菜单命令和事件绑定可编译。
- 手动检查卡片空白区、标题输入框和正文输入框三处右键菜单均能触发删除。
