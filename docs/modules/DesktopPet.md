# 鹈鹕桌宠

从导航中的「鹈鹕桌宠」进入设置页，点击「显示桌宠」。默认关闭；首次开启后，下次启动按保存的状态恢复。退出软件时桌宠也关闭。

红围巾和绿色自行车的鹈鹕按已确认概念稿重绘为分部件 WPF 矢量图形。车轮、踏板、双腿、身体、围巾和头部使用同一动画时钟，不依赖外部图片路径。动画限约 30 帧/秒，窗口关闭和预览页离开时停止计时器。

| 操作 | 行为 |
| --- | --- |
| 鼠标停在身上 | 暂停移动、轻轻歪头；移开后按自动骑行设置恢复 |
| 在头部来回移动鼠标 | 眯眼接受摸头；静止悬停不会误触摸头 |
| 打盹时在头部停留约 0.7 秒 | 睁眼并缓缓抬头，短暂路过不会唤醒 |
| 移动鼠标 | 睁眼时视线跟随鼠标；拖动、菜单与双击加速优先 |
| 单击 | 停车歪头，再继续骑行 |
| 双击 | 加速至设定骑行速度的 2 倍，短时加速后减速 |
| 按住拖动 | 连鸟带车移动，松开后记住位置 |
| 右键 | 骑行、打盹、切换自动骑行、打开设置、隐藏 |
| 自动骑行碰到屏幕边缘 | 撞停、滑下车、发懵、重新上车，约 3 秒后掉头往回骑；拖到边缘不会撞车 |
| 90 秒无互动 | 打盹，点击可唤醒 |

大小支持 60%～160%。骑行速度可设为 10～120 像素/秒（按 WPF 逻辑像素计算），默认 22；修改后自动保存并同步桌宠和动作预览，加速为设定速度的 2 倍。旧设置缺少速度字段时使用默认值。关闭自动骑行会打盹；仍可以点击或拖动。透明窗口不主动激活，透明画面区域不遮盖桌面图像；用户交互只针对角色与自行车的可见部分。

模块布局：`UI/ConvenientNote.DesktopPet.UI`，`src/App/ConvenientNote.DesktopPet.Application`，`src/Modules/ConvenientNote.DesktopPet.Domain`，`src/Infrastructure/ConvenientNote.DesktopPet.Infrastructure`，`src/Contracts/ConvenientNote.DesktopPet.Contracts`。领域层只包含动作状态和设置约束；Windows 窗口、DPI 坐标、绘制与鼠标处理留在 UI。

设置写入数据根目录的 `DesktopPet/settings.json`，通过临时文件和原子替换保存。不读取或修改笔记、待办数据。设置损坏时保留原文件、显示提示且不自动启动桌宠。手动备份并移开损坏设置文件后重启，可恢复默认设置。

当前版本没有喂食养成、AI 聊天、待办联动、开机自启或关闭主程序后独立驻留。混合 DPI 的真实多显示器拖动仍需要在目标硬件上人工验收；已覆盖离屏位置回收及窗口不激活样式。

验证包含纯状态机、设置持久化及失败保护、透明帧/踩踏变化、离屏位置回收、启动导航和六动作渲染，以及真实窗口的显示、动画推进、缩放、关闭停止、恢复和隐藏。
