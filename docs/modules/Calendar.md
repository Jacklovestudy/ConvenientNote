# 日历与行程导入

鼠标位于日历日期区域时，按住 Ctrl 滚动滚轮可缩放日期格和文字，范围60%至200%；普通滚轮上下浏览月份。右上角比例按钮可恢复100%。右侧详情不参与缩放。有已安排日程或待办的日期以加粗边框标识，选中日期继续使用蓝色底色与边框。

日历右上角选择“导入行程”，粘贴全文，再点击“解析并预览”。支持 `【9月24日 周四｜当天安排】` 这样的日期标题，年份优先读取原文，也可以填写默认年份。

每个日期生成一条全天日程，完整每日安排保留在详情中。只有明确成对的交通起止时间才生成独立定时日程；跨午夜支持“次日”。“左右”、时间范围和孤立时间保留原文，不补造时间。全天结束日期在编辑器中包含当天，存储时使用次日零点作为排他结束。

预览可勾选项目，选中一行编辑标题、日期、时间和详情。原文或默认年份修改后必须重新解析。未写截止日期的 `□` 核对事项放在“待安排”，可在预览取消“待安排”并指定日期；它们是日历内的可勾选事项，不依赖待办模块。总路线、背包安排等保存在同一批次的总说明中，完整原文也会保存。

确认导入后自动定位到首个导入日期。日历中点击“详情 / 编辑”修改日程；点击所属行程名称查看总说明和原文。“导入记录”提供历史查看、定位及整批撤销。撤销会移除本批次当前剩余项目，包括导入后修改的项目；不影响其他日程。

相同原文忽略空白行及行首尾空白后禁止重复导入。如需重新导入，先在导入记录撤销原批次。不同原文按不同批次处理，不尝试自动合并语义相似行程。

批次与日程在单个 SQLite 事务中写入，失败全部回滚；批次撤销也使用事务。旧数据库自动添加可选元数据列，原有日程保留。数据按当前工作区隔离。

这期不含通知、ICS 导出或手机日历同步。输入只在本机按规则解析，不联网核验车次、天气或景区开放情况。

原始云南行程回归样例：14条每日安排、3条交通日程、15条核对事项，共32项。

每日详情中的“住宿：”段落会自动显示在日期格的“住 · …”一行及右侧“当晚住宿”区域。房型、入住日期等备注在右侧完整保留；原文明确表示缺少订单或需核对时标为待确认。此功能直接读取已保存的详情，旧行程无需重新导入。跨午夜交通和核对事项不用于提取当晚酒店，没有住宿段落时不沿用上一天的酒店。

旧版默认放在首日的核对事项会自动移回待安排，原有详情与完成状态保留；已改到其他日期的事项不调整。待安排中的事项可以直接完成、编辑或安排到所选日期。
